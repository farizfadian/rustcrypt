## [1.0.0] - 2026-09-09

### 🎉 Initial Release

First public release of RustCrypt - Jasypt-like encryption for Rust, the 5th
member of the GoCrypt / PyCrypt / NodeCrypt / PHPCrypt family.

### Added

#### Core Features
- **AES-256-GCM Encryption** (`Encryptor`) - Modern, authenticated encryption for values shared inside the family (AES-128/192/256 via `with_key_size`)
- **Jasypt Compatible** (`JasyptEncryptor`) - `PBEWithMD5AndDES`, byte-compatible with Java Jasypt's default algorithm
- **Jasypt Strong** (`JasyptStrongEncryptor`) - PBKDF2-HMAC-SHA256 + AES-256-CBC in the family's `PBEWithHmacSHA256AndAES_256` layout
- Pure-Rust implementation on RustCrypto crates: no OpenSSL, no C build step, DES works everywhere

#### ENC(...) Pattern
- `ENC(base64value)` format matching Jasypt/Spring Boot
- `is_encrypted()` helper, `ENC_PREFIX` / `ENC_SUFFIX` constants
- `encrypt_with_prefix()` / `decrypt_prefixed()` on every encryptor
- `decrypt_all_in_string()` (GoCrypt semantics) and `decrypt_all_in_string_lossy()` (NodeCrypt/PyCrypt semantics)
- `decrypt_map()` with `Error::KeyDecrypt` naming the failing key
- `StringEncryptor` trait for generic code and `Box<dyn StringEncryptor>`

#### Config Loaders (feature `config`, default)
- `ConfigLoader` generic over the encryptor (`new` = AES-256-GCM, `with_encryptor` for Jasypt mode)
- `.env` loader, flat YAML loader, JSON loader into any `serde` type with recursive decryption
- `set_to_env()` to export decrypted values to the process environment

#### CLI (feature `cli`, default)
- `rustcrypt encrypt | decrypt | encrypt-file | decrypt-file | version`
- `-p/--password` with `RUSTCRYPT_PASSWORD` fallback, `--no-prefix`, `--jasypt`, `--jasypt-strong`
- Mirrors `gocrypt-cli` messages and exit codes

#### Compatibility & Quality
- Golden vectors generated by GoCrypt v1.0.0 (`tests/fixtures/gocrypt_vectors.json`) for all three modes plus fixed-salt KDF/cipher vectors; RustCrypt reproduces them byte-for-byte
- Live round-trip tests against `gocrypt-cli` and `scripts/cross-check.ps1` for the sibling CLIs
- CI on Linux / Windows / macOS with Rust stable and 1.75 (MSRV), clippy `-D warnings`, rustdoc, cargo-audit
- Release workflow: GitHub Release with binaries for 5 targets and automatic `cargo publish`
